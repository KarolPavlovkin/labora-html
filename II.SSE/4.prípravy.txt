2. KOMENTÁRE A ZÁKLADNÉ ZNAKY V KÓDE – 10 MINÚT

Vysvetlenie komentárov:

Komentár je text v programe, ktorý program nevykonáva. Slúži človeku – programátorovi, spolužiakovi alebo budúcemu autorovi projektu.

V JavaScripte používame dva základné typy komentárov.

A) Jednoriadkový komentár

Zapisuje sa pomocou dvoch lomiek:

// Toto je jednoriadkový komentár
stop();

Všetko, čo je za znakmi // až do konca riadku, program ignoruje.

B) Viacriadkový komentár

Zapisuje sa medzi značky /* a */:

/*
Toto je viacriadkový komentár.
Môžeme doň napísať viac viet.
*/
stop();

Vhodné použitie komentárov:
- názov alebo účel časti kódu;
- vysvetlenie funkcie;
- autor a dátum úpravy;
- označenie jednotlivých sekcií skriptu;
- dočasné vypnutie riadka počas testovania.

Príklad:

// Zastaví prehrávanie animácie na prvom snímku
stop();

/*
Po kliknutí na tlačidlo
sa prehrá ďalšia časť animácie.
*/


Upozornenie:
Komentáre nepoužívame na opis úplne zjavného kódu.

Menej vhodné:
// Priradí číslo 5 do premennej x
let x = 5;

Vhodnejšie:
// Počet opakovaní animácie
let pocetOpakovani = 5;


ZÁKLADNÉ ZNAKY POUŽÍVANÉ V KÓDE

/     lomka – používa sa napríklad v komentároch //
*     hviezdička – používa sa pri komentároch /* */
( )   okrúhle zátvorky – parametre funkcií a podmienky
[ ]   hranaté zátvorky – polia, zoznamy a prístup k prvkom
{ }   zložené zátvorky – blok kódu, funkcie, podmienky
;     bodkočiarka – ukončenie príkazu, podľa štýlu zápisu
" "   úvodzovky – textový reťazec
' '   apostrofy – textový reťazec
` `   spätné úvodzovky – template string v JavaScripte
=     priradenie hodnoty
==    porovnanie hodnoty
===   presné porovnanie hodnoty a typu
!     negácia / „nie“
? :   podmienený operátor
@     zavináč – najmä e-mailové adresy, niekedy špecifické zápisy
|     zvislá čiara, „pipe“
~     vlnovka / tilda


KLÁVESOVÉ SKRATKY – SLOVENSKÁ A ČESKÁ KLÁVESNICA

Dôležité upozornenie:
Skratky sa môžu mierne líšiť podľa operačného systému, typu klávesnice a zvoleného rozloženia. Ak znak nefunguje, treba skontrolovať jazyk klávesnice v systéme.

Na bežnom slovenskom alebo českom rozložení vo Windows sa často používajú:

@     AltGr + V
\     AltGr + Q
|     AltGr + W
~     AltGr + 1

AltGr je pravý kláves Alt.

Ak znak nemožno napísať:
- skúsiť Shift, AltGr alebo prepnutie klávesnice;
- použiť systémovú Tabuľku znakov / Character Map;
- dočasne znak skopírovať z pripraveného dokumentu;
- overiť, či žiak nepoužíva anglické rozloženie klávesnice.

Pripomenutie:
Najčastejšie pri písaní JavaScriptu budeme potrebovať:
( )   { }   [ ]   /   *   "   '   ;   =


3. PÍSANIE A ORGANIZÁCIA SKRIPTOV – 8 MINÚT

Učiteľ otvorí Adobe Animate a zobrazí panel Akcie.

Otvorenie panelu Akcie:
Window > Actions
alebo kláves F9.

V paneli Actions môžeme:
- písať kód priamo k snímke časovej osi;
- písať kód priradený objektu;
- upravovať existujúci kód;
- kontrolovať syntax;
- pridávať komentáre;
- pracovať so samostatnými súbormi skriptov.

Odporúčania pri písaní kódu:

1. Kód odsadzujeme.
2. Jednotlivé časti oddelíme prázdnym riadkom.
3. Používame zmysluplné názvy premenných.
4. Dôležité časti vysvetľujeme komentárom.
5. Nezapisujeme všetok kód do jedného neprehľadného bloku.
6. Súbory pomenúvame jednoznačne.

Nevhodný názov súboru:
novy.js
test2.js
aaaa.js

Vhodný názov súboru:
uvodna_animacia.js
ovladanie_tlacidiel.js
navigacia_menu.js
scena1_stop.js

Príklad prehľadného zápisu:

// Zastavenie animácie na prvom snímku
stop();

// Nastavenie názvu projektu
let nazovProjektu = "Moja animácia";

// Výpis informácie do konzoly
console.log(nazovProjektu);


4. IMPORT A EXPORT SKRIPTOV V ADOBE ANIMATE – 10 MINÚT

Vysvetlenie pojmov:

IMPORT SKRIPTU
Import znamená načítanie existujúceho súboru skriptu do projektu alebo do panela Actions.

EXPORT SKRIPTU
Export znamená uloženie napísaného skriptu z projektu do samostatného externého súboru.

Prečo importovať a exportovať skripty?

- môžeme si vytvoriť knižnicu vlastných kódov;
- rovnaký skript môžeme použiť vo viacerých projektoch;
- zálohujeme si kód aj mimo súboru .fla;
- môžeme kód upravovať aj v inom editore;
- práca v tíme je jednoduchšia;
- externý súbor sa ľahšie zdieľa.

PRÁCA SO SKRIPTOM V ADOBE ANIMATE

Učiteľ predvedie postup na projektore.

A) Otvorenie miesta pre kód

1. Otvoriť dokument v Adobe Animate.
2. Vybrať snímku na časovej osi, napríklad prvý snímok.
3. Otvoriť Window > Actions alebo stlačiť F9.
4. Kliknúť do oblasti pre zápis kódu.

B) Napísanie krátkeho skriptu

Príklad:

// Zastaví animáciu na aktuálnom snímku
stop();

C) Export skriptu

V paneli Actions sa otvorí ponuka panelu, zvyčajne ikona s čiarami alebo malá šípka v pravom hornom rohu.

Postup môže byť podľa verzie Adobe Animate mierne odlišný, ale princíp je rovnaký:

1. V paneli Actions otvoriť ponuku panela.
2. Vybrať možnosť Export Script alebo Save Script.
3. Zvoliť miesto uloženia.
4. Zadať zrozumiteľný názov súboru.
5. Uložiť správnu príponu:
   - .js pri dokumente HTML5 Canvas,
   - .as pri ActionScript dokumente.

D) Import skriptu

1. Označiť miesto, kam chceme skript vložiť.
2. Otvoriť panel Actions klávesom F9.
3. V ponuke panela vybrať Import Script alebo Load Script.
4. Vybrať súbor .js alebo .as.
5. Skontrolovať vložený kód.
6. Uložiť dokument a otestovať ho.

Upozornenie:
Po importe vždy skontrolujeme:
- či je vybraný správny snímok;
- či je skript vložený do správnej vrstvy;
- či ide o správny typ dokumentu;
- či skript neobsahuje chyby;
- či názvy objektov v skripte zodpovedajú názvom objektov na ploche.

Dôležité:
Skript pre ActionScript 3.0 nemusí fungovať v dokumente HTML5 Canvas a naopak. Pred importom treba vedieť, aký typ dokumentu používame.


5. PRAKTICKÉ CVIČENIE ŽIAKOV – 9 MINÚT

ZADANIE PRE ŽIAKOV

1. Otvorte nový alebo pripravený dokument v Adobe Animate.
2. Vyberte prvý snímok časovej osi.
3. Otvorte panel Actions klávesom F9.
4. Vložte tento kód:

/*
Autor: Meno a priezvisko

Téma: Komentáre v skripte
*/

5. Doplňte svoje meno a triedu.
6. Pridajte ešte jeden vlastný jednoriadkový komentár.
7. Skript exportujte ako súbor:

alebo
meno_priezvisko_komentar.as

8. Ak to čas dovolí, importujte pripravený skript od učiteľa a skontrolujte, čo robí.

Rozširujúca úloha pre rýchlejších žiakov:

Doplňte kód:

// Výpis správy pri spustení dokumentu
console.log("Animácia bola spustená.");

Vysvetlite, na čo slúži komentár a na čo slúži príkaz console.log().
